## 📖 Overview

PySlate is a completely client-side Python execution environment that runs in your browser. It requires no backend, no server installation, and no account. Write code, handle live inputs, and render visualizations instantly.

## ✨ Key Features

* **In-Browser Execution:** Runs Python completely client-side using WebAssembly.
* **Live Input Handling:** Synchronous `input()` prompts pause execution without freezing the UI.
* **Offline Capabilities:** Progressive Web App (PWA) with a network-first caching strategy.
* **Persistent Storage:** Auto-saves drafts and named projects locally to your browser.
* **Visual Output:** Native support for `matplotlib` and custom `turtle` canvas rendering.

## 🛠️ Tech Stack

* HTML5 / CSS3 / JavaScript
* **Pyodide:** CPython compiled to WebAssembly.
* **CodeMirror:** Syntax highlighting and formatting.
* **Service Workers:** Offline support and caching.
